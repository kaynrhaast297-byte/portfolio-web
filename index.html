Detalhes técnicos de ImovelSP — Sistema Imobiliário
Problema
Facilitar a comparação de imóveis e organizar informações de preço, localização e características durante a busca.
Solução
Aplicação com busca paginada, filtros, página de imóvel, comparação de preços, formulário de contato e rotas de API documentadas no repositório.
Decisões técnicas
  • Next.js e TypeScript para organizar páginas, componentes e rotas de API.

Limitações
  • MVP com funcionalidades e integrações dependentes dos dados e da configuração do ambiente.
  • A comparação usa os imóveis disponíveis. O README registra o escopo e as evoluções planejadas; os testes do deploy precisam de validação própria.

Detalhes técnicos de DevCheck
Problema
Reunir verificações e suas evidências antes do push, distinguindo falhas bloqueantes, ressalvas e erros operacionais.
Solução
CLI com configuração validada, perfis de checagem e relatórios estruturados, acompanhados por um dashboard local com histórico e logs.
Decisões técnicas
  • Separar o resultado de cada verificação da decisão da política local e da autorização de publicação.
  • Registrar execuções e expor seu acompanhamento em um dashboard local, com atualizações por Server-Sent Events.
  • Apresentar evidências históricas com versão, ambiente e limitações, mantendo os comprovantes privados fora do site.
Limitações
  • Candidata alpha 3.0.0a6 em avaliação. O código e os comprovantes completos de CI permanecem privados.
  • A captura usa dados fictícios; não há demonstração interativa pública. Os resultados registrados não comprovam domínio individual de todo o código.
  • As checagens dependem das ferramentas e da política configuradas. A aprovação local exige uma decisão separada para publicação.

Projeto 03 Protótipo · privado

Indústria · Validação de software

CNC Copilot

Protótipo em TypeScript e React para revisar dados nominais e rastrear inconsistências em estudos de torno CNC. Idealizado e conduzido por mim, com IA em toda a implementação.

  • TypeScript
  • React
  • Zod
  • Node.js
  • Vite
Ver estudo de caso
Detalhes técnicos de CNC Copilot
Problema
Organizar dados de ordem de serviço, desenho, máquina e setup sem confundir informações propostas ou cálculos nominais com autorização operacional.
Solução
Interface de revisão com contratos tipados, extração determinística limitada, referências documentais rastreáveis e regras para explicitar ausências, divergências e bloqueios.
Decisões técnicas
  • Separar proposta extraída, declaração humana e referência documental; cada informação preserva sua origem.
  • Invalidar avaliações anteriores quando os dados ou o escopo de revisão mudam.
  • Manter a comparação nominal separada das permissões de planejamento operacional, exportação e execução.
Limitações
  • Protótipo privado em desenvolvimento, sem homologação para fabricação ou operação de máquina.
  • Testes de software e build não comprovam segurança física, fixação, dinâmica ou ausência de colisões 3D.
  • Sem demonstração interativa pública ou código CNC operacional neste portfólio. As sete permissões permanecem bloqueadas no recorte verificado.

Detalhes técnicos de Portfólio Pessoal
Problema
Permitir que recrutadores conheçam meu perfil e encontrem evidências dos projetos sem depender de serviços externos para acessar o conteúdo principal.
Solução
Página estática com navegação por seções, projetos disponíveis no HTML e links distintos para demonstração, código e detalhes técnicos.
Decisões técnicas
